# Running the Application

This project is a Qt application based on `qmake`.
The project file to use is `BibliotecaVirtuale.pro`.

## Prerequisites

You need Qt installed, including `qmake` and the Qt Widgets libraries.

## Build

From the root, run:

```bash
mkdir -p build
cd build
qmake ../BibliotecaVirtuale.pro
make
```

## Run

```bash
./BibliotecaVirtuale
```
